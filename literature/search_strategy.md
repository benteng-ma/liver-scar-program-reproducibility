# Phase 0 literature-search strategy

Search date: 2026-08-30 (Asia/Shanghai).

Sources searched were PubMed/PMC, Europe PMC full text and supplementary files, GEO, NCBI BioProject/SRA, ArrayExpress/BioStudies, the Human Cell Atlas data portal, Dryad links exposed by the primary publication, and general web search used only to locate primary records.

Core query families:

- `human liver cirrhosis single cell public dataset`
- `human liver fibrosis single nucleus public`
- `HBV cirrhosis single cell GEO`
- `NASH OR MASH fibrosis single cell human liver`
- `alcohol cirrhosis single cell human`
- `cholestatic fibrosis single cell human`
- `human liver fibrosis spatial transcriptomics`
- `published scar program donor pseudobulk external validation`
- `leave-study-out leave-etiology-out scRNA snRNA liver fibrosis`
- `matched random gene modules spatial validation liver cirrhosis`
- exact accession searches for GSE136103, GSE181483, E-MTAB-10553, GSE202379, GSE210077, GSE244832, GSE290642, GSE185477 and PRJNA833766.

An exact duplicate required one study to contain all eight prespecified elements: multiple published-program inventory, data-lineage audit, donor-level pseudobulk, leave-study-out, leave-etiology-out, scRNA-to-snRNA transfer, spatial validation and matched random modules. No retrieved paper met all eight. This is a search-limited novelty conclusion, not proof that no unpublished or unindexed work exists.

The 2026 paper *Progressive suppression of regulated cell death defines terminal macrophage states in liver cirrhosis* was audited in full because it combines GSE136103, GSE181483 and E-MTAB-10553. It is a close thematic competitor but not an exact duplicate of the benchmark. Its apparent 31-sample integration must not be interpreted as 31 independent donors because the E-MTAB-10553 processed object itself embeds GSE136103 cells.
